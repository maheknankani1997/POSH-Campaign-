## Publish with GitHub Pages
1. Upload `index.html` and the `assets` folder to the root of a GitHub repository.
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your main branch and `/ (root)`, then save.
5. GitHub will provide a public URL such as:
   `https://YOUR-USERNAME.github.io/YOUR-REPO/`

Keep the `assets` folder beside `index.html` so the creative images load correctly.
